# **App Name**: DraftSense

## Core Features:

- Scenario Selection: A directory of templates that are fully translated.
- Structured Fact Input: Forms with input fields for context sanitization.
- Tone & Formality Control: Allows the user to control tone applied to the prompt.
- Draft Output: Display the generated draft in an editable box with 'Copy to Clipboard' feature.
- Theme Toggle: Users can switch between light and dark themes that is persistent across sessions.
- Draft Generation: Generates the email drafts, factoring in user-selected scenario, input, and tone using an LLM tool.
- Multilingual Support: Allows the user to switch between different languages.

## Style Guidelines:

- Primary color: Soft blue (#A0CFEC), conveying trust and accessibility.
- Background color: Light gray (#F0F4F8) for light theme, dark gray (#333333) for dark theme, providing comfortable contrast.
- Accent color: Teal (#4DB6AC) for interactive elements, offering a clear visual cue.
- Body font: 'Inter', sans-serif, for clear and accessible reading in all UI elements.
- Headline font: 'Space Grotesk', sans-serif, providing a balance of modernity and readability.
- Use simple, outlined icons to represent different email templates and actions.
- Clean and structured layout with ample white space to improve readability and reduce visual clutter.
- Subtle animations and transitions to provide feedback and enhance the user experience, especially when generating drafts.
